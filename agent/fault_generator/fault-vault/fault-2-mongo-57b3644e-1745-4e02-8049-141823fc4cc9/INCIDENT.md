# Storefront Category Products Displayed in Reverse Order

## Title
Storefront Category Products Displayed in Reverse Order

## Description
Users are reporting that when they browse products by category on the storefront, the items are displayed in reverse alphabetical order (Z-A) instead of the expected alphabetical order (A-Z). This issue is consistent across all categories and affects all users. Monitoring shows that the catalogue service is responding successfully to requests for products by category, but the order of the items in the response payload appears to be reversed.
