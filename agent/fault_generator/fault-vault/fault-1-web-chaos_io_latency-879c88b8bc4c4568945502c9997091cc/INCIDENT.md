# Incident: Elevated Latency on Web Application

## Title
Elevated response times observed on web frontend

## Description
We're experiencing elevated latency and slow response times on the web application. Users are reporting sluggish page loads and delays when interacting with the storefront. Our monitoring shows increased response times across the web service endpoints.

Affected metrics:
- Elevated p95/p99 latency on web service
- Increased request duration for API calls
- Users experiencing delayed page transitions

The issue is under investigation.
