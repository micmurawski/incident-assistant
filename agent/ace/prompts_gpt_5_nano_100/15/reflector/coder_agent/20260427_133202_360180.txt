# ROLE
You are an expert Site Reliability Engineer (SRE) specializing in incident analysis and response. Your task is to conduct a precise, in-depth diagnostic evaluation of the coder_agent agent's actions during an incident response scenario.
Deliver actionable insights to strengthen future agent performance.

# OBJECTIVE
First, determine the task **outcome** from the assessment/ground truth:
- **Failed / Partially failed**: Identify the exact "Moment of Divergence" where the agent's strategy moved from optimal to failure. Analyze why the Playbook failed to prevent this.
- **Succeeded**: Focus on extracting `useful_facts` and reinforcing what worked (`helpful` tags). Only propose a `playbook_amendment` if a clear inefficiency is observed (e.g., wasted tool calls, unnecessary loops).

# DIAGNOSTIC LENSES
1. **The Pivot Point**: Identify the specific step where the agent's strategy failed.
2. **Playbook Omission/Ignorance**: Did the agent have a relevant rule but ignore it because it was too vague? Did a rule exist that, if followed, would have prevented the error?
3. **Knowledge Acquisition**: Did the agent rely on assumptions about the app architecture/environment instead of actively querying for facts?
4. **Task Delegation Audit**: Did the agent fail to delegate a complex sub-task? If delegation occurred, was it assigned to the correct expert agent, and was the context/instruction clear and actionable?
5. **Observation Blindness**: Did the agent receive a tool error or subtle hint in a result that it failed to process correctly?

# PLAYBOOK EVALUATION
Tag every existing bullet:
- `helpful`: Directly contributed to a correct sub-decision. (+1)
- `neutral`: Irrelevant to this specific scenario. (0)
- `harmful`: Misled the agent, caused a loop, or encouraged a suboptimal strategy. (-1)

# OUTPUT INSTRUCTIONS: `reflect` / `reflect_on_assignment` tools
Choose ONE tool per reflection:
- Use `reflect` for self-reflection on `coder_agent`.
- Use `reflect_on_assignment` when the root issue is in delegated execution by another assignee. In this case:
  - `assignee` = delegated assignee slug.

## Required fields
- `reasoning`: Structured analysis. For failures use numbered "5 Whys" format (1. Why...? 2. Why...? ...). For successes describe what went right and what facts were discovered.
- `error_identification`: For failures — categorize precisely (e.g., "Tool Parameter Hallucination", "Observation Blindness"). For successes — set to "N/A - Success" (optionally note inefficiencies).
- `root_cause_analysis`: For failures — why the error occurred. For successes — "N/A" or note minor inefficiency root cause.
- `correct_approach`: The ideal tool-call sequence the agent should have followed. For successes, confirm the agent's approach was correct or note the optimal shortcut.
- `key_insight`: One high-impact principle to remember.
- `bullet_tags`: JSON list of existing bullet evaluations.
- `useful_facts`: STATIC, verified facts about the app discovered in this trace (e.g., "The cart service connects to Redis on port 6379 — observed in kubectl_describe output"). Include source anchor. Do NOT put strategies here.
- `playbook_amendment`: Optional candidate heuristic. Provide ONLY when a concrete failure/divergence occurred and no equivalent bullet exists. Format: "IF [observable condition] THEN [specific tool action]". Set to `null` when not justified.

+PromMetrics['CACHE_HITS'] = Counter('payment_cache_hits', 'Cache hits per endpoint', ['endpoint'])
+PromMetrics['CACHE_MISSES'] = Counter('payment_cache_misses', 'Cache misses per endpoint', ['endpoint'])
+PromMetrics['CACHE_EVICTIONS'] = Counter('payment_cache_evictions', 'Cache evictions per endpoint', ['endpoint'])
+PromMetrics['CACHE_SIZE'] = Gauge('payment_cache_size', 'Number of items in in-memory cache', ['endpoint'])
+PromMetrics['ENDPOINT_REQUESTS'] = Counter('payment_endpoint_requests', 'Requests per endpoint', ['endpoint'])

+# In-memory LRU cache for per-id user lookups
+class LRUCache:
+    def __init__(self, capacity=256, ttl=300, eviction_callback=None):
+        self.capacity = capacity
+        self.ttl = ttl
+        self.lock = threading.Lock()
+        self.cache = OrderedDict()
+        self.eviction_callback = eviction_callback
+
+    def get(self, key):
+        with self.lock:
+            if key not in self.cache:
+                return None
+            value, ts = self.cache[key]
+            if (time.time() - ts) > self.ttl:
+                # expired
+                self.cache.pop(key, None)
+                if self.eviction_callback:
+                    self.eviction_callback(key)
+                return None
+            # refresh order and timestamp
+            self.cache.move_to_end(key)
+            self.cache[key] = (value, time.time())
+            return value
+
+    def set(self, key, value):
+        with self.lock:
+            if key in self.cache:
+                self.cache.pop(key)
+            self.cache[key] = (value, time.time())
+            self.cache.move_to_end(key)
+            if len(self.cache) > self.capacity:
+                oldest, (old_val, old_ts) = self.cache.popitem(last=False)
+                if self.eviction_callback:
+                    self.eviction_callback(oldest)
+
+    def __len__(self):
+        with self.lock:
+            return len(self.cache)
+
+# Eviction callback to increment per-endpoint eviction metric
+def eviction_cb(key):
+    endpoint = 'unknown'
+    try:
+        if isinstance(key, str) and key.startswith('check_user:'):
+            endpoint = 'check_user'
+    except Exception:
+        pass
+    PromMetrics['CACHE_EVICTIONS'].labels(endpoint=endpoint).inc()

+def _update_cache_metrics(endpoint):

+            exists = (req.status_code == 200)
+        except requests.exceptions.RequestException as err:
+            app.logger.error(err)
+            return str(err), 500
+        finally:
+            try:
+                req.close()
+            except Exception:
+                pass
+        payment_cache.set(cache_key, exists)
+        _update_cache_metrics('check_user')
+        anonymous_user = not exists
+
+    # Validate cart
+    has_shipping = False
+    for item in cart.get('items', []):
+        if item.get('sku') == 'SHIP':

+

+        except Exception:
+            pass

+    PromMetrics['AVS'].observe(cart.get('total', 0))
+

+

+            except Exception:

+        app.logger.error(err)
+        return str(err), 500
+    finally:
+        try:
+            req.close()
+        except Exception:
+            pass
+
+    return jsonify({ 'orderid': orderid })

+if __name__ == '__main__':
+    port = int(os.getenv('SHOP_PAYMENT_PORT', '8080'))
+    app.run(host='0.0.0.0', port=port)

                # Cache implementation
                class LRUCache:
                    def __init__(self, capacity=100, ttl=60, eviction_callback=None):
                        self.capacity = capacity
                        self.ttl = ttl
                        self.lock = threading.Lock()
                        self.cache = OrderedDict()
                        self.eviction_callback = eviction_callback

                    def get(self, key):
                        with self.lock:
                            if key not in self.cache:
                                return None
                            value, ts = self.cache[key]
                            if (time.time() - ts) > self.ttl:
                                # expired
                                self.cache.pop(key, None)
                                if self.eviction_callback:
                                    self.eviction_callback(key)
                                return None
                            # refresh order
                            self.cache.move_to_end(key)
                            self.cache[key] = (value, time.time())
                            return value

                    def set(self, key, value):
                        with self.lock:
                            if key in self.cache:
                                self.cache.pop(key)
                            self.cache[key] = (value, time.time())
                            self.cache.move_to_end(key)
                            if len(self.cache) > self.capacity:
                                oldest, (old_val, old_ts) = self.cache.popitem(last=False)
                                if self.eviction_callback:
                                    self.eviction_callback(oldest)

                    def __len__(self):
                        with self.lock:
                            return len(self.cache)

                class LRUCache:
                    def __init__(self, capacity=256, ttl=60, eviction_callback=None):
                        self.capacity = capacity
                        self.ttl = ttl
                        self.lock = threading.Lock()
                        self.cache = OrderedDict()
                        self.eviction_callback = eviction_callback

                    def get(self, key):
                        with self.lock:
                            if key not in self.cache:
                                return None
                            value, ts = self.cache[key]
                            if (time.time() - ts) > self.ttl:
                                # expired
                                self.cache.pop(key, None)
                                if self.eviction_callback:
                                    self.eviction_callback(key)
                                return None
                            # refresh order
                            self.cache.move_to_end(key)
                            self.cache[key] = (value, time.time())
                            return value

                    def set(self, key, value):
                        with self.lock:
                            if key in self.cache:
                                self.cache.pop(key)
                            self.cache[key] = (value, time.time())
                            self.cache.move_to_end(key)
                            if len(self.cache) > self.capacity:
                                oldest, (old_val, old_ts) = self.cache.popitem(last=False)
                                if self.eviction_callback:
                                    self.eviction_callback(oldest)

                    def __len__(self):
                        with self.lock:
                            return len(self.cache)

                # In-memory LRU cache for per-id user lookups
                class LRUCache:
                    def __init__(self, capacity=256, ttl=60, eviction_callback=None):
                        self.capacity = capacity
                        self.ttl = ttl
                        self.lock = threading.Lock()
                        self.cache = OrderedDict()
                        self.eviction_callback = eviction_callback

                    def get(self, key):
                        with self.lock:
                            if key not in self.cache:
                                return None
                            value, ts = self.cache[key]
                            if (time.time() - ts) > self.ttl:
                                # expired
                                self.cache.pop(key, None)
                                if self.eviction_callback:
                                    self.eviction_callback(key)
                                return None
                            # refresh order and timestamp
                            self.cache.move_to_end(key)
                            self.cache[key] = (value, time.time())
                            return value

                    def set(self, key, value):
                        with self.lock:
                            if key in self.cache:
                                self.cache.pop(key)
                            self.cache[key] = (value, time.time())
                            self.cache.move_to_end(key)
                            if len(self.cache) > self.capacity:
                                oldest, (old_val, old_ts) = self.cache.popitem(last=False)
                                if self.eviction_callback:
                                    self.eviction_callback(oldest)

                    def __len__(self):
                        with self.lock:
                            return len(self.cache)

                # In-memory LRU cache for per-id user lookups
                class LRUCache:
                    def __init__(self, capacity=256, ttl=60, eviction_callback=None):
                        self.capacity = capacity
                        self.ttl = ttl
                        self.lock = threading.Lock()
                        self.cache = OrderedDict()
                        self.eviction_callback = eviction_callback

                    def get(self, key):
                        with self.lock:
                            if key not in self.cache:
                                return None
                            value, ts = self.cache[key]
                            if (time.time() - ts) > self.ttl:
                                # expired
                                self.cache.pop(key, None)
                                if self.eviction_callback:
                                    self.eviction_callback(key)
                                return None
                            self.cache.move_to_end(key)
                            self.cache[key] = (value, time.time())
                            return value

                    def set(self, key, value):
                        with self.lock:
                            if key in self.cache:
                                self.cache.pop(key)
                            self.cache[key] = (value, time.time())
                            self.cache.move_to_end(key)
                            if len(self.cache) > self.capacity:
                                oldest, (old_val, old_ts) = self.cache.popitem(last=False)
                                if self.eviction_callback:
                                    self.eviction_callback(oldest)

                    def __len__(self):
                        with self.lock:
                            return len(self.cache)

                    def __init__(self, capacity=256, ttl=60, eviction_callback=None):
                        self.capacity = capacity
                        self.ttl = ttl
                        self.lock = threading.Lock()
                        self.cache = OrderedDict()

                    def get(self, key):
                        with self.lock:
                            if key not in self.cache:
                                return None
                            value, ts = self.cache[key]
                            if (time.time() - ts) > self.ttl:
                                # expired
                                self.cache.pop(key, None)
                                if self.eviction_callback:

                                return None
                            # refresh order and timestamp
                            self.cache.move_to_end(key)
                            self.cache[key] = (value, time.time())

                class LRUCache:
                    def __init__(self, capacity=256, ttl=300, eviction_callback=None):
                        self.capacity = capacity
                        self.ttl = ttl
                        self.lock = threading.Lock()
                        self.cache = OrderedDict()
                        self.eviction_callback = eviction_callback

                    def get(self, key):
                        with self.lock:
                            if key not in self.cache:
                                return None
                            value, ts = self.cache[key]
                            if (time.time() - ts) > self.ttl:
                                # expired
                                self.cache.pop(key, None)
                                if self.eviction_callback:
                                    self.eviction_callback(key)
                                return None
                            # refresh order and timestamp
                            self.cache.move_to_end(key)
                            self.cache[key] = (value, time.time())
                            return value

                    def set(self, key, value):
                        with self.lock:
                            if key in self.cache:
                                self.cache.pop(key)

                            self.cache.move_to_end(key)

                                oldest, (old_val, old_ts) = self.cache.popitem(last=False)
                                if self.eviction_callback:
                                    self.eviction_callback(oldest)

                    def __len__(self):
                        with self.lock:
                            return len(self.cache)
