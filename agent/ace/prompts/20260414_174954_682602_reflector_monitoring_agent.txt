### 4. Root Cause Identified

**The root cause is a missing API endpoint**: The current catalogue API provides:
- `/api/catalogue/products` - returns ALL products
- `/api/catalogue/categories` - returns list of categories  
- `/api/catalogue/product/{sku}` - returns single product by SKU

**However, there is NO endpoint for filtering products by category** (e.g., `/api/catalogue/products?category=X` or `/api/catalogue/category/{name}`).

When users browse products by category, the frontend is likely making a request to a non-existent category-filter endpoint, resulting in a 404 error.

### Recommended Fix
The catalogue service needs a new endpoint to support category-based product filtering, such as:
- `GET /api/catalogue/products?category={category_name}` - filter by query parameter
- `GET /api/catalogue/category/{category_name}` - filter by category path

This would require code changes to the catalogue service to implement the filtering logic.
